# TeamPlanner

Веб-приложение для управления командными задачами.

## Стек

- React
- TypeScript
- Vite
- ESLint

## Возможности

- Создание и редактирование задач
- Kanban-доска
- Изменение статуса задач
- Поиск и фильтрация
- Приоритеты и дедлайны

## Запуск проекта

```bash
npm install
npm run dev
